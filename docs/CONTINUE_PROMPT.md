```text
Работи исклучиво во репозиториумот Aevyra-Messaging-Gateway.

Целата комуникација, документација и кориснички текст остануваат на македонски со кирилично писмо. Техничките идентификатори може да останат на англиски.

Пред промени прочитај ги применливите AGENTS.md, HANDOFF.md, README.md, docs/PROJECT_BRIEF.md, ROADMAP.md, PROGRESS.md, TESTING.md, ARCHITECTURE.md и DECISIONS.md. Провери ги package.json, lockfile, миграциите и релевантниот код. Не претпоставувај резултат од стар чат.

Прва задача: независно провери го Чекор 4В-2В-1. Не започнувај Чекор 5.

1. Потврди дека REAL_SENDING_ENABLED=false без да печатиш тајни.
2. Не применувај миграции или provision врз постојната развојна база. Интеграциските тестови нека користат само сопствени привремени aevyra_test_* бази и улоги.
3. Изврши lint, typecheck, npm test и build. Не стартувај HTTP/UI тест додека build ја менува истата .next папка.
4. Само по успешен build, изврши:
   - npm.cmd run test:contact-basis-write-ui
   - npm.cmd run test:contact-basis-ui
   - npm.cmd run test:contact-basis-http
5. Провери ги recovery сценаријата за 503, 401, мрежа/timeout, OUTCOME_UNKNOWN, IDEMPOTENCY_CONFLICT, непотполн или неконзистентен 2xx, оштетен и недостапен sessionStorage, стар RECORD replay по WITHDRAW и зачувување на истиот idempotency клуч.

По независно прифаќање на 4В-2В-1, предложи го следниот најмал чекор според ROADMAP.md со проверливи критериуми. Не избирај нов gateway или библиотека без одделна одлука.

Во извештајот наведи: изменети датотеки, точни проверки, тест-ресурси и нивно чистење, отворени проблеми и дали чекорот е прифатлив.
```
